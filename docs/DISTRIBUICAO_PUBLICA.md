# Distribuição pública — estado e limites

## O que está preparado

- Repositório público com documentação e capturas reais.
- Pacote local de teste baseado no `DQM3_PTBR_Auditoria_PC_Atualizacao_13_DLCs.zip`.
- Instalador local com verificação SHA-256, seleção da pasta do jogo, cópia de segurança, manifesto e script de restauração.

## O que não deve ser publicado agora

O pacote local de teste inclui o bundle completo do jogo. Não o envie para o GitHub, GitHub Releases, Steam Community Guides ou outro serviço público sem confirmar os direitos e as permissões necessários. O fato de a alteração principal ser uma tradução não implica, por si só, autorização para redistribuir o bundle que contém dados do jogo.

## Próximas etapas para uma distribuição pública

1. Confirmar os direitos e permissões aplicáveis à distribuição de um patch de tradução.
2. Avaliar um formato de patch que não redistribua arquivos originais do jogo desnecessariamente.
3. Validar o patch em uma instalação Steam limpa e na build suportada.
4. Confirmar o funcionamento dentro do jogo, inclusive as três DLCs.
5. Publicar documentação, checksums, instruções de instalação e restauração.
6. Criar uma Release pública somente com os arquivos cuja distribuição esteja autorizada.

## Limitações técnicas conhecidas

O manifesto da Atualização 13 registra validação estrutural do ZIP, UnityFS, AES, tamanho do CAB e preservação de nomes de monstros. O teste final dentro do jogo continua marcado como pendente de confirmação do usuário.

## Aviso

Este é um projeto comunitário não oficial, sem afiliação à Square Enix. Esta documentação não constitui autorização ou aconselhamento jurídico sobre direitos de distribuição.
