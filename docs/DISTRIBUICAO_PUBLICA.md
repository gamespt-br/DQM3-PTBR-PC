# Distribuição do Tradutor PT-BR v1.0

## Estado atual

O repositório público contém documentação e capturas do jogo traduzido. O pacote local do instalador contém um bundle do jogo e permanece destinado a teste local.

## Antes de uma distribuição pública

- Confirmar as permissões necessárias para distribuir o patch.
- Preparar um formato de patch que evite redistribuir dados originais do jogo desnecessariamente.
- Testar instalação e restauração em uma instalação limpa da versão de PC compatível.
- Publicar somente arquivos cuja distribuição esteja autorizada.

O pacote local de teste não deve ser enviado ao GitHub Releases, à Comunidade Steam ou a outros serviços públicos antes dessa revisão.
