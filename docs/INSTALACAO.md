# Instalação — situação atual

A documentação definitiva de instalação pública ainda está em preparação.

O procedimento atualmente testado pelo responsável do projeto é destinado à versão PC/Steam e substitui o bundle correspondente na pasta de dados do jogo. Antes de recomendar esse procedimento a terceiros, será publicado um instalador ou patch com verificação de versão e backup automático.

## Recomendações para futuros testes

- Faça backup dos arquivos originais.
- Não use arquivos de outra versão do jogo.
- Mantenha o idioma do jogo conforme indicado no pacote correspondente.
- Verifique a compatibilidade após atualizações oficiais.
- Não baixe executáveis ou arquivos de fontes não oficiais.

**Não use este documento como instrução de instalação ainda.** A versão pública será atualizada quando o pacote de distribuição tiver passado por revisão.
