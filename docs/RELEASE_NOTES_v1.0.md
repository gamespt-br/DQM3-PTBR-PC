# Tradutor PT-BR v1.0 — Notas da versão

Primeira versão do tradutor comunitário para português brasileiro de DRAGON QUEST MONSTERS: The Dark Prince para PC/Steam.

## Conteúdo do pacote

- Instalador: `Instalar_PTBR.cmd` e `Instalar_PTBR.ps1`.
- Restaurador: `Restaurar_PTBR.cmd` e `Restaurar_PTBR.ps1`.
- Instruções: `LEIA-ME.txt`.
- Um único arquivo de dados de localização modificado, dentro de `bundle/`.

O pacote não contém o jogo completo, executável nem a estrutura completa da instalação.

## Instalação e restauração

O instalador procura a instalação Steam automaticamente e, se necessário, permite selecionar a pasta que contém `DQMonsters3.exe` e `DQMonsters3_Data`. Antes de substituir o arquivo, valida o recurso de origem e cria um backup verificado.

Para restaurar, execute `Restaurar_PTBR.cmd`. O restaurador procura o backup associado à instalação e verifica os hashes antes de restaurar. Uma alteração posterior do arquivo — por exemplo, causada por atualização do jogo — interrompe a restauração para evitar sobrescrever dados mais recentes.

Ao iniciar um jogo novo, selecione **Espanhol (Español)**.

## Compatibilidade

Preparado para a versão de PC testada pelo responsável do projeto. Atualizações do jogo podem exigir uma versão atualizada do tradutor.
