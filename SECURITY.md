# Segurança do repositório

Este repositório é público e destina-se à documentação e às capturas de tela do projeto de tradução PT-BR.

## Não envie

- Senhas, tokens de acesso, chaves privadas ou arquivos de autenticação.
- Dados pessoais, saves ou arquivos de configuração privados.
- Executáveis, DLLs, bundles, assets ou cópias dos arquivos originais do jogo.
- Pacotes modificados do jogo sem revisão prévia do método de distribuição.

O arquivo `.gitignore` contém regras preventivas, mas não substitui a revisão antes de cada commit. O GitHub também pode reter dados removidos no histórico de commits; portanto, nunca envie segredos, mesmo que pretenda apagá-los depois.

## Reportar um problema

Abra uma Issue descrevendo o problema sem incluir credenciais, saves pessoais ou arquivos proprietários do jogo. Para situações sensíveis, não publique detalhes exploráveis em uma Issue pública; entre em contato com o mantenedor pelo perfil GitHub.

## Segurança da conta

Use autenticação em dois fatores no GitHub, mantenha os métodos de recuperação atualizados e nunca compartilhe tokens ou senhas. Nunca informe sua senha do GitHub, Steam ou Square Enix a alguém que ofereça ajuda com a tradução.
