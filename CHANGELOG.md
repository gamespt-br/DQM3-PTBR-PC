# Histórico de versões

## Tradutor PT-BR v1.0 — primeira versão

- Primeira versão do tradutor comunitário para PC/Steam.
- Distribuição em um ZIP simples com o arquivo de localização modificado, instruções rápidas e checksum SHA-256.
- Instalação manual pela substituição de um único arquivo de localização, com backup original feito pelo usuário e restauração pela cópia de segurança.
- Idioma obrigatório ao iniciar um jogo novo: **Espanhol (Español)**.
- Compatibilidade preparada para a versão de PC testada pelo responsável do projeto.
- Aviso público reforçado: projeto gratuito, independente e não oficial; o pacote contém somente um arquivo de dados de localização modificado e exige uma cópia do jogo adquirida separadamente.
